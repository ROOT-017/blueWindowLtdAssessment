# blueWindowLtdAssessment

How to run the project

## Prerequisites

- Node.js (v14 or later)
- npm (v6 or later)

## Installation

Clone the repository:
`git clone {repository-url}`
Navigate to the project directory:
`cd blueWindowLtdAssessment`

# Frontend

Install the frontend dependencies:
`cd frontend`
`npm install`

# Backend

Install the backend dependencies:
`cd backend`
`npm install`

## Running the Project
### Frontend
To start the frontend, run:
`cd frontend`
`npm run start`
This will start the React development server and open the application in your web browser.

### Backend
To start the backend, run:
`cd backend`
`npm run start`

This will start the Express server on port 3000.
